# Loan Management System

A full-stack loan management system built with Django and React/TypeScript.

## Project Overview

This system allows for the management of loans, including:
- User authentication and management
- Loan creation, approval, and tracking
- Payment scheduling and processing

## Technology Stack

- **Backend**: Django with Django REST Framework
- **Frontend**: React with TypeScript
- **Development Environment**: Docker
